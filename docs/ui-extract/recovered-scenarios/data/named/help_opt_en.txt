#------------------------------------------------------------------------------
# 画面設定

fullscreen
	Switch between windowed mode and fullscreen.

sqscr
	Switch between 16:9 and 4:3 aspect ratios.

noeffect
	Turn effects on/off.

scanim_on
	Turn performance demanding animation on/off.
scanim_off
	Turn performance demanding animation on/off.	Still images will be used in place when turned off.

esccancel_on
	Set esc key function.	Assigns same function as right click cancel.
esccancel_off
	Set esc key function.	Panic Button: A panic button behavior can be set below.

panictype_0
	Set panic button behavior.	Minimize: Minimizes the game to the taskbar.
panictype_1
	Set panic button behavior.	Image 1: Dummy image 1 is displayed. Press esc to cancel.
panictype_2
	Set panic button behavior.	Image 2: Dummy image 2 is displayed. Press esc to cancel.
panictype_3
	Set panic button behavior.	Custom: Custom image is displayed. Select an image file after pressing this button.

stayontop
	When switched on, the game window is going to always be on top.

item_icon_chk
	Switch mode icon display on/off.
#	ゲーム中の進行状態アイコンの表示を設定します。
item_vprg_chk
	Switch voice playback and auto mode wait time progress meter.
item_qmlk_chk
	Determine if the menu at the bottom of the screen is always visible.	If this setting is off, hovering over the bottom of the screen will still bring the menu up.
item_toch_chk
	Rearrange the UI to be touch-screen optimized.

chapthidetime
	Change the chapter display settings. The leftmost option hides the current chapter while playing, the middle option hides after a set amount of seconds, and the rightmost option keeps displayed at all times.

bgmhidetime
	Change how long the BGM title is displayed when a new BGM starts to play. Dragging the slider to the far left will make the title never display whereas dragging it to the far right keeps it always displayed.


facemode_on
	When portrait mode is switched on, character portraits will usually be displayed next to the text box with some exceptions.
facemode_off
	When portrait mode is switched off, no character portraits will be displayed next to the text box with some exceptions.

qcpopover
	Change how menu bar pop-up windows are accessed.

#------------------------------------------------------------------------------
# ゲーム進行

readskip
	Switch auto skip/jump for read text on/off.	Auto-skip that is in progress can be stopped with left-click.

readjump
	Set whether read text should be automatically skipped or jumped over.

curmove
	Switch automatic cursor movement on/off for confirmation popups.

curmoveyes_on
	Mouse cursor will always be moved to "Yes" when a confirmation popup is displayed. 
curmoveyes_off
	Mouse cursor will be moved to "No" when a confirmation popup is displayed.	For some confirmation popups such as quicksave, it will be "Yes."


curhidestep_0
	Set mouse cursor to never be hidden.
curhidestep_5	curhidestep_10	curhidestep_20	curhidestep_x
	Set mouse cursor to be hidden after it has not been moved for the set amount of seconds.

filedclk_off
	Let a single click save or load.
filedclk_on
	Require double-clicking to save or load.

hsel_area
	Fixate H-scene choices.

flowshow_on	flowshow_off
	Turn this on to show the entire flow chart at all times, including scenes you haven't reached.

stopdeactive_on
	Set whether game is to be paused when game window is inactive.	Pause: The game is paused.
stopdeactive_off
	Set whether game is to be paused when game window is inactive.	Continue: The game keeps running.

icpreview
	Switch taskbar preview on/off.
#	This function is available for Windows Vista and higher.

suspend_on	suspend_off
	Turn the suspend function that allows you to resume your game where you previously left on startup on or off.

#===============================

drawspeed
	Change the speed at which the game is running.

vspeed
	Change the voice playback speed.	Caution: Sound quality will drop when speed is increased.

vspeedsync_chk
	Synchronize voice playback speed with game speed.	Only works in the range between x1.0 and x3.0.

skipspeed	skipspeed_rail
	Adjust skip mode speed.	Ctrl key skipping is always conducted at the maximum speed regardless.

skipst_0
	Set the skip style.	Normal: Update screen/music with all changes while skipping.
skipst_1
	Set the skip style.	Fast: Omit changes of facial expressions and poses of sprites.
skipst_2
	Set the skip style.	Text: Only display text without updating display/music.

movierclick
	Set whether to skip movies by right-clicking. (It does not matter if this is the first time the movie is being played)

movieskip
	Set whether to continue skipping if previously watched movie is reached during skip mode.

drama_on
	Switch dramatic mode on/off.	On: Text box will be hidden for voiced lines during auto mode.
drama_off
	Switch dramatic mode on/off.	Off: Text box is always displayed.

use_speech
	Launch external TTS tool for reading out unvoiced lines.

snapsilent

snapdetail

# テキスト設定

textspeed
	Set the drawing speed of the text.

autospeed
	Set the auto mode speed.

atextwait
	Set adittional waiting time per character in auto mode. The final waiting time will be the sum of adding the number of text characters and the basic waiting time.

	Set voice playback waiting behavior during auto mode.	Normal: Always wait until voice has finished playing.
autovwait_1
	Set voice playback waiting behavior during auto mode.	Voice: Wait until voice has finished playing only when following line is voiced.

	Set voice playback waiting behavior during auto mode.	Speed: Always advance according the set auto mode speed.

	Set whether all or only read text should be skipped in skip mode.

	Set whether only read or all text should be skipped with ctrl skip.	${_allSkip?"Cannot be set when the above is set to on.":"Only read text will be skipped."}

	Set whether auto mode should be canceled or not after choices.

	Change text box color for other POVs. After clicking this button,	use the color palette to the right to choose a color.
color_hwin
	Change text box color for H-scenes. After clicking this button,	use the color palette to the right to choose a color.
color_text
	Change the text color of regular text. After clicking this button,	use the color palette to the right to choose a color.
color_read
	Change the text color of read text. After clicking this button,	use the color palette to the right to choose a color.

nohwindow_chk
	Set whether to use a small window display during H-scenes	No matter if it's enabled or disabled, the window color change will still happen.

hsv
	Current color settings for the selected type of text or text box.	${hsv?"Drag the round pins to adjust color.":""}

hsv_reset
	Reset color settings for the currently selected type of text or text box.

HSV_DRAG_H
	Changing color brightness/saturation.
HSV_DRAG_SV
	Changing color hue.

winsample
	Displays a text sample with all the current settings applied.

winopac
	Adjust the opacity of the text box.

fontselect
	Change the font.
