# 畫面設定

fullscreen
	全螢幕、窗口顯示模式切換。

sqscr
	１６：９模式與４：３模式切換。

noeffect
	設定畫面效果。

scanim_on
	設定高特效動畫效果。
scanim_off
	設定高特效動畫效果。	關閉時將使用靜態圖像代替。

esccancel_on
	設定ＥＳＣ按鍵功能。	取消：與滑鼠右鍵功能相同。
esccancel_off
	設定ＥＳＣ按鍵功能。	老闆鍵：分類下欄選擇的功能。

panictype_0
	選擇老闆鍵功能。	最小化：窗口最小化。
panictype_1
	選擇老闆鍵功能。	畫像１：顯示圖像１。再次按下ESC解除。
panictype_2
	選擇老闆鍵功能。	畫像２：顯示圖像２。再次按下ESC解除。
panictype_3
	選擇老闆鍵功能。	用戶自訂：按下按鈕後，請選擇一個圖像文件。

stayontop
	開啟時遊戲窗口始終顯示在最前方。


item_icon_chk
	設定遊戲中進度圖示是否顯示。
item_vprg_chk
	設定遊戲中語音播放和自動等待時間進度是否顯示。
item_qmlk_chk
	設定遊戲中螢幕底部功能按鈕是否顯示。	關閉狀態下滑鼠移動至此可以暫時顯示。
item_toch_chk
	設定觸控按鈕功能是否顯示。

chapthidetime
	設定遊戲中的章節標題是否顯示。	左端始終隱藏，中間會在指定時間（單位秒）後自動隱藏，右端始終顯示。

bgmhidetime
	設定遊戲中播放音樂的標題是否顯示。	左端始終隱藏，中間會在指定時間（單位秒）後自動隱藏，右端始終顯示。


facemode_on
	啟用後，即使顯示立繪，角色的臉部表情也會顯示在消息窗口中。	（但在某些情況下不會顯示）
facemode_off
	關閉時，當顯示立繪時，消息窗口中不再顯示角色的臉部表情。	（但在某些情況下不會隱藏）

qconfpop_over	qconfpop_rclick
	設置操作方法以顯示窗口菜單附帶的彈出功能。

# ゲーム進行

readskip
	設置是否自動跳過/跳轉已閱讀的文本。	快進中可以透過單擊滑鼠左鍵來暫停。

readjump
	選擇快進模式的跳過/跳轉操作。

curmove
	設定滑鼠指針是否自動移動。

curmoveyes_on
	確認時滑鼠指針自動移動到“是”按鈕上。
curmoveyes_off
	確認時滑鼠指針自動移動到“否”按鈕上。	但是對於某些確認（例如快速保存與載入），移動到“是”按鈕上。


curhidestep_0
	設定滑鼠指針是否自動隱藏。
curhidestep_5	curhidestep_10	curhidestep_20	curhidestep_x
	設定滑鼠指針是否自動隱藏。	在指定的時間後隱藏滑鼠指針。
filedclk_off
	保存/載入操作隻需單擊滑鼠。
filedclk_on
	保存/載入操作需要雙擊滑鼠。

hsel_area
	設置是否固定Ｈ場景選擇項。

flowshow_on	flowshow_off
	打開時，即使未達到對應劇情，也將顯示全部流程圖。

stopdeactive_on
	設置停止操作遊戲一段時間後會發生什麼事。	停止：暫停遊戲並靜音。
stopdeactive_off
	設置停止操作遊戲一段時間後會發生什麼事。	繼續：繼續遊戲而不停止。

icpreview
	設置任務欄的窗口預覽顯示。
#	僅在Windows Vista及更高版本有效。

suspend_on	suspend_off
	設置是否在開始遊戲後立即恢復上一次進度。

drawspeed
	設置遊戲進行速度。

vspeed
	設置遊戲語音播放速度。	請注意，提高速度會降低音質。

vspeedsync_chk
	語音播放速度與遊戲進行速度保持一致。	僅在x1.0～x3.0範圍之間有效。

skipspeed	skipspeed_rail
	設置快進模式速度。	按下Ctrl按鍵是總以最快速度快進。

skipst_0
	設置快進方式。	普通：即使在快進過程中，也會顯示所有螢幕更新。
skipst_1
	設置快進方式。	快進：快進時跳過臉部表情和姿勢的變化。
skipst_2
	設置快進方式。	純文字：快進時僅顯示文字，螢幕和音樂不會更新。

movierclick
	播放動畫時是否允許滑鼠右鍵跳過。	（即便是第一次觀看，右鍵也可以跳過）

movieskip
	如果快進到已經觀看過的動畫，是否直接跳過，繼續快進。

drama_on
	設置沉浸式體驗。	開：在自動模式下，在有語音時隱藏文本窗口。
drama_off
	設置沉浸式體驗。	OFF：在自動模式下，即使有語音時也顯示文本窗口。

use_speech
	使用外部語音引擎以讀取沒有語音的文本。	可以從選單欄上的“文字/文本閱讀”中進行詳細設置。

	設置自動模式速度。

atextwait
	設置自動模式每個文字的等待時間。

ctrlskip_off

color_read
	設置已讀文字的顏色。	選擇此按鈕後，在右欄中設置顏色。

nohwindow_chk
	設置在Ｈ場景期間是否使用窗口顯示。
